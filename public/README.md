# Product Images

Place your product images in this folder with the following names:

## Required Images:

1. **school-uniforms.jpg** - Image of school uniforms
2. **tshirts.jpg** - Image of t-shirts
3. **polo-shirts.jpg** - Image of polo shirts
4. **sports-jerseys.jpg** - Image of sports jerseys

## Image Recommendations:

- **Format**: JPG, PNG, or WebP
- **Size**: Minimum 600x400 pixels (landscape orientation works best)
- **Quality**: High resolution for best display
- **File size**: Keep under 500KB for faster loading

## How to Add Images:

1. Save your product photos with the exact names listed above
2. Place them in this `public` folder
3. The website will automatically display them in the products section

## Example:
```
public/
  ├── school-uniforms.jpg
  ├── tshirts.jpg
  ├── polo-shirts.jpg
  └── sports-jerseys.jpg
```

If you want to use different image names, update the `image` property in the `products` array in `src/pages/index.js`.
